# Дані книг для фікстур

Для будь-яких тестових/сід-даних із книгами бери РЕАЛЬНІ книги через
`mcp__openlibrary__search_books`, не вигадуй `bookKey`/обкладинки.

- Виклич інструмент, візьми `key`, `title`, `authors`, `coverUrl` з результату.
- `key` (напр. `/works/OL...W`) — це наш `bookKey`; використовуй його як є.
- Для детермінованих тестів зафіксуй конкретні значення у фікстурі
  (не викликай мережу в самому тесті — за скілом write-tests усе за MockEngine).
- coverUrl бери з інструмента; не конструюй руками.
