# Dispatch matrix — ReadShelf

| Тип задачі | Субагент | Топологія | Нотатки |
|---|---|---|---|
| пошук по коду / «де X» | explorer | Hub→1 | повертає список, не код |
| рев'ю по вимірах | reviewer ×N | Hub→N паралельно | 1 вимір + code-review skill |
| написання тестів | test-writer | Hub→1 | за write-tests skill |
| мутаційна перевірка | mutator | **ІЗОЛЬОВАНО (worktree)** | пише в дерево — не поруч із reviewer |
| взаємозалежне обговорення | — | Peer Mesh | рідко; поки не застосовуємо |

## Cost-per-topology (цей прогін)
- Монолітний 1 агент: читає все сам → головний контекст роздувається, послідовно.
- Hub-and-Spoke ×5: токенів ≈ стільки ж чи більше (у кожного свій контекст), але
  головний контекст лишився чистим, а час ≈ найповільніший субагент, не сума.
- Урок: мутатор, що писав у спільне дерево, забруднив вимір reviewer → двоє здали
  хибні блокери. Read-only fan-out має бути справді read-only; усе, що мутує дерево — у worktree (М7).
