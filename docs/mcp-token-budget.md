# MCP token budget — openlibrary.search_books

Запит: `q=dune, limit=10`.

| Варіант | Байти | ~Токени (÷4) |
|---|---|----------|
| Сирий Open Library (усі поля) | 10703 | 2676     |
| З `fields=` (5 полів) | 1502 | ~375     |

**Висновок:** обрізанням полів на боці інструмента економимо ~86% контексту
на кожен виклик. Наш MCP-вихід ще менший — він
викидає обгортку й лишає 5 полів із готовим `coverUrl`.

**Правило:** MCP-інструменти повертають лише потрібні поля, ніколи не сирі
відповіді зовнішнього API — сирий JSON роздуває контекст агента задарма.
